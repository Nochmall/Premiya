# Премия за добрые дела — редизайн (предложение)

Статичная копия лендинга с правками по макету в Figma: новый первый экран, иллюстрация с каплей,
счётчик добрых дел, меню разделов, кнопка «наверх», мобильная адаптация (Mobile <768 · Tablet 768–1023 ·
Desktop S 1024–1279 · Desktop L ≥1280).

Сайт — в папке `original/` (`index.html`, `politika.html`, `zayavka.js`), без сборки.

> Форма отправляет данные на `/api/photo` и `/api/zayavka` — в этой копии бэкенда нет, отправка не работает.
